# freetokens 是如何运作的

## 一行代表什么

一条**免费线路**＝一个模型 × 一个渠道 × 一个免费条件。每条免费线路都会记录该免费计划何时开始、何时公布或预计结束、我们上次核查它是什么时候，以及支撑这些日期的事件。每条事实都链接到其来源。

**状态：**
- **有效：** 我们上次调用它时有响应。
- **已过公布截止但仍有效：** 已过公布的结束日期，但依然有效。
- **标称免费（未实测）：** 厂商把它标为免费，但我们没有调用过。
- **不响应：** 目录里有列出，但上次核查时不可用。
- **已结束：** 不再免费，并附有能说明这一点的对应事件。

**截止日期置信度：**
- **official（官方）：** 厂商公布了该日期。
- **inferred（推算）：** 由公布的持续时长推得（"自 9 月 26 日起两周"），推理过程写在备注里。

## "我们实测"

这些是我们自己测出来的限制，例如能同时跑通多少个 coding-agent 任务。每项测量都来自我们自己的账号，只跑一次，强度很轻，并附上测量日期。它绝不是压力测试，也绝不构成任何保证。请不要对共享的免费额度做压力测试。

## AA 指数与 EST（估算 AA 指数）

**AA 指数**就是 [Artificial Analysis](https://artificialanalysis.ai) Intelligence Index。只有 Artificial Analysis 发布了它时才会展示，并且它链接到该站上对应模型的页面。

新模型和未公开模型通常没有 AA 指数。对这类模型我们显示一个 **EST** 区间，宽度恒为 5 分（例如 `EST 43–48`），由公开基准分数推算得出。

EST 区间如何算出：
1. **收集公开分数。** 我们记录该模型的公开分数并附上来源。官方、排行榜、第三方以及社区或泄露的结果都算数，但必须是针对这一个确切模型的，绝不能是传闻中的身份或前代型号。
2. **用参考模型为每个基准做拟合。** 对每个基准，我们选取既在同一基准上有分数、又有官方 AA 指数的参考模型。至少需要 4 个，然后拟合一条直线。只有拟合的相关系数不低于 0.6 时该基准才会被采用。目前（Oct 6）参与拟合的基准：AI Coding Daily（17 个参考模型，r = 0.85）、SWE-bench Verified（110，r = 0.82）、SWE-bench Pro（62，r = 0.87）、Terminal-Bench 2.1（77，r = 0.87）。当某个参考模型在同一基准上有多个已公布分数时，我们取它们的中位数。
3. **把每个基准换算成隐含 AA 值。** 模型的分数代入该基准的拟合直线。
4. **合并。** 用加权中位数合并这些隐含值：官方与排行榜来源权重 1，第三方 0.75，社区与泄露 0.5。
5. **生成区间。** 区间以该中位数为中心，宽 5 分。
6. **最低证据量。** 至少需要 1 个以上述方式拟合的基准（在此之前站点显示 `EST —`）。仅基于单个基准得出的 EST 会在其证据面板里标注 "1 benchmark"，请把它当作粗略指引。

部分题集（例如 GPQA 只取其中 60 题）会被列出，但不参与计算。

**EST 如何参与排名：**
- 带 EST 的模型按其区间中值，与官方 AA 分数放在一起排序。
- 它们不会拿到单个名次，只有一个区间，例如 "约 #10–15"。
- 有官方 AA 分数的模型之间按 #1、#2、#3…… 排名。带 EST 的模型插在它们之间："≈#2–3" 表示它会落在官方 #2 与 #3 之间。
- 首页先显示分数最高的 10 个模型；点 "Show all" 展开其余，包括没有 AA 分数、证据也不足以估算的模型。
- 当 Artificial Analysis 公布官方分数后，EST 会被替换，同时我们记录官方分数是否落在原区间之内。

点击任意 EST 徽章上的 ⓘ，可查看所用的每个基准、其来源，以及被排除的分数为何被排除。

全部数据与方法的参数都在本仓库：[`data/benchmarks.json`](data/benchmarks.json)、[`data/anchors.json`](data/anchors.json)，以及 [`schema/schema.json`](schema/schema.json) 中的 `est_rules`。

## 渠道的入场成本

"免费"仍可能需要先付出些东西。每个渠道在 [`data/channels.json`](data/channels.json) 中有一条记录，写明最省事的入门方式及其来源：

- **$0 · 无需账号**：不付费、不注册即可使用。
- **$0 · 需注册**：注册后免费，不需要银行卡。
- **$0 · 仅邀请**：免费，但注册需要邀请，或他在别处已有一定历史的账号。
- **先订套餐**（例如 $10/mo）：必须先有生效的付费订阅，免费模型才可用。
- **先充值**（例如 $20）：需要达到最低充值额度。

需要先花钱的渠道上的免费线路，在任何出现处都带一个小小的 **$** 标记，"无需付费"筛选会把它们隐藏起来。

## 免费模型的使用方式

每个渠道还在 [`data/channels.json`](data/channels.json)（`access`）中记录其免费模型以何种方式可达，并附来源：

- **API · 协议格式**：用 API key 从你自己的工具就能调。徽章会写出该格式名（OpenAI chat、OpenAI Responses、Anthropic Messages、Gemini），或写出它接受几种格式。
- **仅 CLI**：免费模型只在厂商自己的 CLI 或 app 内响应（例如 OpenCode Zen 的免费模型在 OpenCode 之外返回 403）。
- **仅 App**：只能在厂商的桌面端或网页 app 内使用。
- **仅限人工**：条款禁止脚本、机器人或自主 agent。

几乎所有厂商共有的规则（不得转售访问、一人一号、不得批量注册账号）处处适用，不在每个渠道重复写明。当某条免费线路的免费路径与所属渠道不同，它可以覆盖渠道的设定。

## 使用场景视图

顶栏的切换开关（All · Humans · Agents）按一种使用场景展示整个站点。它从不改变分数，只决定哪些免费线路计入。

- **All**：全部免费线路（有效、标称免费（未实测），或已过公布截止但仍响应）。
- **Humans**：无需先付费的免费线路。只在厂商自己的 app 或 CLI 内可用、或条款禁止自动化的线路仍然计入：人可以手工使用它们。
- **Agents**：脚本或 coding agent 可以使用的免费线路：API key 可行，或厂商 CLI 可无人值守运行。条款禁止自动化的线路（"仅限人工"）以及只在桌面端或网页 app 内可用的线路被排除。需要先付费套餐的线路保留，并用 **$** 标注。

在同一视图内，模型只在该视图可用的模型之间排名（官方 AA 分数在前，估算分插在它们之间）。只能通过不符合本视图的线路获得免费的模型，被列在底部 "Not usable this way"（此方式不可用）。仅限某一地区的免费线路仍留在每个视图中，并带地区标签。视图选择会记在你的设备上，也可以通过 `?use=humans` 或 `?use=agents` 分享。

## 备用顺序

在 Agents 视图下，首页会显示该先用哪条免费路径、以及它耗尽之后往下退到哪一级。

- **吞吐量档位。** 每条免费线路可以带一个粗略档位：*一天几十个*（约 100 次请求或更少）、*一天几百个*（或只能同时跑几个），或 *同时 10+ 个、全天*（我们实测能同时跑通 10 个以上的 agent 任务）。该档位来自该路径公布的限额，或来自我们自己的并发实测，线路上会记录是哪一种。我们从不为了测量而把额度跑空：确切数字会随账号、IP 和日期变化，所以粗略档位能保持更久的准确。
- **阶梯。** 从最宽松的一档开始，取该档的最高分。向更不宽松的档位下移时，某条路径只有在分数比它下面每一级都高出 2 分以上时才配得上一级台阶，因为更小的额度只有换来明显更聪明的模型才值得。与某一级领先者相差 2 分以内的其他路径，作为替补列出（EST 区间的宽度本身就大于 2 分）。
- **计入范围。** 只计入 agent 可用（API key 可用，或 CLI 条款允许自动化）且有分数的路径。默认只计入我们实测通过的路径；勾选 *Include unconfirmed* 后，标称免费但我们尚未跑通的路径也会计入。

## 厂商

每个模型都在 `data/makers.json` 中指向一个厂商（名称、母公司、国家、官方链接）。同一家公司的不同写法在那里合并（例如 THUDM 归到 Z.ai 名下）。未公开模型归属 "Undisclosed"（未公开）；当社区把某个模型同某厂商联系起来时，该模型会带上 `suspected_maker` 及其来源，在模型页显示为 "possibly X · unconfirmed"（疑似 X · 未经证实），并在该厂商页单独列为 "Possibly theirs"（疑似其出品）列表。它绝不被算作该厂商自己的模型。

## 厂商自报数字与对比表（ADR-023）

厂商会在自己的评测框架里报告自家模型的基准分数，而小模型在编码基准上的分数往往明显高于其总体智能所应得出的水平。把这些原始数字直接套用一个从独立排行榜学来的拟合关系，会高估它们（Xing 4.0 29B 算出来是 27；而它厂商的表格把它与 Qwen3.6 35B A3B（AA 18）摆在同一水平）。因此，来自对比表的厂商分数要拿同一张表里的其他模型来读：对每个已知 AA 分数、且基准分数在 10 分以内的对照模型，隐含 AA 等于该模型的 AA 加上拟合斜率乘以分数差，并对最接近的模型给予更大权重。估算值取各基准的加权平均。没有可用对照模型的厂商自报分数，区间宽度加倍，并标为低置信度。

## 隐私与复查

本站不设 cookie，也不记录会话。页面浏览量与点击了哪些外链由 PostHog 统计（欧盟托管、仅存内存、IP 匿名化、尊重 Do Not Track）；页面展示时向自家服务器发一个空请求（用于区分人与爬虫，不携带任何标识符）；并读取标准 web 服务器日志（页面、时间、referrer、user agent）来统计访问量与 AI 爬虫。没有任何东西能跨访问识别你；具体机制见 OBSERVE.md。一条有效免费线路若 7 天未复查，就被标为"待复查"，在重新核查之前不再计入已确认。

## 免费计划（offers）

免费线路指的是某个模型在某渠道上费用为 $0，并带有只为阻止滥用而设的上限。免费计划给你的则是可以在多个模型之间通用的一些东西：额度、每日发放量（Neurons、Freebucks、一份共享调用配额）、学生计划，或随你已在付费的套餐附带的一项权益。计划有自己的独立页面（/offers），绝不与模型一起排名；模型页把它们列在 "Also free through"（还可这样免费用）之下。数量保留各厂商自己的单位，从不折算。列表按计划拿到的难易排序（要求最少的在前），其次按补充频率。只列出官方且合规的途径。一个计划 14 天未复查即待复查。

## 存疑清单

1. **状态标签的英中对照**：术语表强制 lane→免费线路、live→有效、listed→标称免费（未实测）、past end→已过公布截止但仍有效、ended→已结束，本文已全文统一采用。但生成的表格里这些状态是以英文（配 emoji）出现的，中文读者在正文与表格之间会遇到两种说法；若需加英文角注请告知。
2. **未进术语表的标签**：`official` / `inferred`（截止日期置信度）、`not answering`、`All · Humans · Agents`（顶栏开关）、`*Include unconfirmed*`、以及 UI 文案 `Not usable this way` / `Also free through` / `Possibly theirs` / `Undisclosed` 一律保留英文原样，只在括号内给出中文，便于与界面/数据值对照。若要求全部译成中文，需另行统一。
3. **`Volume tier` / `The ladder`**：备用顺序的两个子项译为「吞吐量档位」「阶梯」，术语表未收；「一级台阶 / 替补」为自定译法。
4. **`harness`** 译为「评测框架」、**`fit slope`** 译为「拟合斜率」、**`stand-ins`** 译为「替补」，均无术语表依据。
5. **`plan first` / `top-up first`** 译为「先订套餐」「先充值」；数据里的对应英文值形如 `$10/month plan first`，若中文站点要显示数据原文，需再对齐。
6. **`AA index`** 统一译为「AA 指数」，但 `Artificial Analysis Intelligence Index` 作为官方专有名称保留英文。
7. **`(Oct 6)` 未译为日期中文**：按「不译日期」规则保留原文；如要求「10 月 6 日」形式请告知，我会统一改成。
8. **`coding agent` / `agent`** 保留英文（技术通用词，且 `usable by agents` 已定译为「agent 可用」）。
