# freetokens 是如何运作的

## 一行代表什么

一条**免费线路**＝一个模型 × 一个渠道 × 一个免费条件。每条免费线路都会记录该免费计划何时开始、何时公布或预计结束、我们上次核查它是什么时候，以及支撑这些日期的事件。每条事实都链接到其来源。

SiliconFlow 以价格表为准，目录 price 只作线索。

**状态：**
- **有效：** 我们上次调用它时有响应。
- **已过公布截止但仍有效：** 已过公布的结束日期，但依然有效。
- **标称免费（未实测）：** 厂商把它标为免费，但我们没有调用过。
- **不响应：** 目录里有列出，但上次核查时不可用。
- **已结束：** 不再免费，并附有能说明这一点的对应事件。

**截止日期置信度：**
- **official（官方）：** 厂商公布了该日期。
- **inferred（推算）：** 由公布的持续时长推得（"自 9 月 26 日起两周"），推理过程写在备注里。

## "我们实测"

这些是我们自己测出来的限制，例如能同时跑通多少个 coding-agent 任务。每项测量都来自我们自己的账号，只跑一次，强度很轻，并附上测量日期。它绝不是压力测试，也绝不构成任何保证。请不要对共享的免费额度做压力测试。

## FT Intelligence（FTI）

**FTI** 是全站统一使用的一条智力分，由 freetokens 根据公开基准分数计算，刻度在 2026 年 11 月 1 日一次定下，任何单个来源改版都不会让它移动。所有模型走同一套方法。

显示方式：
- `FTI 33`：至少 3 个来源，其中至少 1 个独立于模型厂商（Artificial Analysis 不算这一个），任意两个来源相差不超过 8 分，且没有来源的值被截在刻度的下限或上限。
- `FTI 31–36`：来源不足，或只有厂商自报的数字。以计算出的中心为准，宽 5 分的区间。3 个以上来源相差超过 8 分时也显示区间：此时会把 Artificial Analysis 作为多一个来源加入并重新计算，仍然分歧的话保持区间。
- `—`：暂时没有可用来源。

计算方法：
1. **收集公开分数。** 我们记录每个模型的公开基准分数并附上来源。排行榜、第三方、厂商与社区的结果都算数，但必须是针对这一个确切模型的，绝不能是传闻中的身份或前代型号。部分题集会被列出，但不参与计算。
2. **每个基准只拟合一次。** 一组参考模型有冻结的 FTI 参考分。对每个基准，我们选取同一基准上也有分数的参考模型，拟合一条直线。只有参考模型至少 4 个、相关系数不低于 0.6、且多数参考模型没有挤在同一个分数上（地板或天花板效应）时，该基准才会被采用。厂商自报的分数比独立测试偏高，所以够数量时单独拟合一条线。目前：AI Coding Daily（r = 0.89, 17 个参考模型）、Aider Polyglot（r = 0.94, 17 个参考模型）、SWE-bench Verified（r = 0.72, 86 个参考模型）、SWE-bench Pro（r = 0.82, 25 个参考模型）、Terminal-Bench 2.1（r = 0.76, 45 个参考模型）、LiveCodeBench（r = 0.76, 9 个参考模型）、tau-bench（r = 0.81, 6 个参考模型）、GPQA Diamond（r = 0.61, 68 个参考模型）、Humanity's Last Exam（r = 0.74, 46 个参考模型）以及 Epoch AI Benchmarking Hub（Epoch Capabilities Index，r = 0.89，95 个参考模型，另有其中 12 个基准）。拟合线在 [`data/ft_lines.json`](data/ft_lines.json)。
3. **把每个基准换算成隐含 FTI。** 模型的分数代入该基准的拟合直线。分数远超出参考模型覆盖范围时，按范围边缘读取。
4. **合并。** 用加权中位数合并这些隐含值。排行榜来源权重 1，第三方与 Artificial Analysis 0.75，社区与泄露 0.5，厂商自报 0.4。厂商对比表里如果还列了有已知参考分的模型，就与这些模型对照读取（隐含值＝对方的分数加拟合线斜率乘以分差，权重 0.6），厂商自己的评测框架因此被抵消。
5. **计数来源。** Epoch AI 的所有基准合计算一个来源。同一基准上的多条声明只算一次。
6. **Artificial Analysis 只是其中一个来源。** 其他来源不足 3 个、或 3 个以上来源相差超过 8 分时才使用，权重同第三方，只列名字和链接。
7. **快照。** 权重在同一个名字下被替换的模型只有一条记录，附 `snapshots`（id、日期、出处，最后一个为当前）。每条证据带上它测的是哪个快照，算分只用当前快照的证据。没有快照标注的证据按日期归属；两者都不知道时按当前处理。当前快照还没有证据时，改用旧证据并显示为区间。走势图从各快照的日期起使用该快照自己的分数，所以升级不会改写之前的日子。只有当用户能在同一渠道上长期按 ID 选择新旧版本时，才拆成单独的模型条目。第三方渠道实际提供哪个快照大多不知道；只有查实它提供的是旧快照时，线路才记 `serves`。
8. **推理模式。** 证据的模式（思考或档位）写在它的 variant 里。没有说明时按厂商默认配置计，同一基准的不同模式绝不混算。

来源：AI Coding Daily、SWE-bench、Scale SEAL、Terminal-Bench、Vals AI、llm-stats、Aider、LiveCodeBench、BFCL、tau-bench、厂商模型卡与技术报告、[Artificial Analysis](https://artificialanalysis.ai)，以及 [Epoch AI](https://epoch.ai/benchmarks)（Epoch AI，"Capabilities & benchmarking"，epoch.ai/benchmarks，CC BY 4.0；只使用其主基准数据与 Epoch Capabilities Index）。

**排名。** 分数以整数发布。模型按其分数中心排序。显示为整数的模型得到单个名次（`#7`）；显示为区间的模型得到名次范围（`#10–15`），对照其他所有已评分模型的中心计算。首页先显示分数最高的 10 个模型；点「展开全部」展开其余，包括没有可用来源的模型。

点击任意 FTI 旁的 ⓘ，可查看每个来源的数值与链接，以及被列出但未采用的分数为何未采用。

全部数据与方法的参数都在本仓库：[`data/benchmarks.json`](data/benchmarks.json)、[`data/ft_lines.json`](data/ft_lines.json)、[`data/ft_scores.json`](data/ft_scores.json)，以及 [`schema/schema.json`](schema/schema.json) 中的 `ft_rules`。

## 渠道的入场成本

"免费"仍可能需要先付出些东西。每个渠道在 [`data/channels.json`](data/channels.json) 中有一条记录，写明最省事的入门方式及其来源：

- **$0 · 无需账号**：不付费、不注册即可使用。
- **$0 · 需注册**：注册后免费，不需要银行卡。
- **$0 · 仅邀请**：免费，但注册需要邀请，或他在别处已有一定历史的账号。
- **先订套餐**（例如 $10/mo）：必须先有生效的付费订阅，免费模型才可用。
- **先充值**（例如 $20）：需要达到最低充值额度。

需要先花钱的渠道上的免费线路，在任何出现处都带一个小小的 **$** 标记，"无需付费"筛选会把它们隐藏起来。

## 免费模型的使用方式

每个渠道还在 [`data/channels.json`](data/channels.json)（`access`）中记录其免费模型以何种方式可达，并附来源：

- **API · 协议格式**：用 API key 从你自己的工具就能调。徽章会写出该格式名（OpenAI chat、OpenAI Responses、Anthropic Messages、Gemini），或写出它接受几种格式。
- **仅 CLI**：免费模型只在厂商自己的 CLI 或 app 内响应（例如 OpenCode Zen 的免费模型在 OpenCode 之外返回 403）。
- **仅 App**：只能在厂商的桌面端或网页 app 内使用。
- **仅限人工**：条款禁止脚本、机器人或自主 agent。

几乎所有厂商共有的规则（不得转售访问、一人一号、不得批量注册账号）处处适用，不在每个渠道重复写明。当某条免费线路的免费路径与所属渠道不同，它可以覆盖渠道的设定。

## 使用场景视图

顶栏的切换开关（All · Humans · Agents）按一种使用场景展示整个站点。它从不改变分数，只决定哪些免费线路计入。

- **全部**：全部免费线路（有效、标称免费（未实测），或已过公布截止但仍响应）。
- **人用**：无需先付费的免费线路。只在厂商自己的 app 或 CLI 内可用、或条款禁止自动化的线路仍然计入：人可以手工使用它们。
- **Agent 用**：脚本或 coding agent 可以使用的免费线路：API key 可行，或厂商 CLI 可无人值守运行。条款禁止自动化的线路（"仅限人工"）以及只在桌面端或网页 app 内可用的线路被排除。需要先付费套餐的线路保留，并用 **$** 标注。

在同一视图内，模型只在该视图可用的模型之间排名（按 FTI 排名，区间模型得到名次范围）。只能通过不符合本视图的线路获得免费的模型，被列在底部 「该用途不可用」。仅限某一地区的免费线路仍留在每个视图中，并带地区标签。视图选择会记在你的设备上，也可以通过 `?use=humans` 或 `?use=agents` 分享。

## 备用顺序

在「Agent 用」视图下，首页会显示该先用哪条免费路径、以及它耗尽之后往下退到哪一级。

- **吞吐量档位。** 每条免费线路可以带一个粗略档位：*一天几十个*（约 100 次请求或更少）、*一天几百个*（或只能同时跑几个），或 *同时 10+ 个、全天*（我们实测能同时跑通 10 个以上的 agent 任务）。该档位来自该路径公布的限额，或来自我们自己的并发实测，线路上会记录是哪一种。我们从不为了测量而把额度跑空：确切数字会随账号、IP 和日期变化，所以粗略档位能保持更久的准确。
- **备用顺序。** 从最宽松的一档开始，取该档的最高分。向更不宽松的档位下移时，某条路径只有在分数比它下面每一级都高出 2 分以上时才配得上一级台阶，因为更小的额度只有换来明显更聪明的模型才值得。与某一级领先者相差 2 分以内的其他路径，作为替补列出（区间的宽度本身就大于 2 分）。
- **计入范围。** 只计入 agent 可用（API key 可用，或 CLI 条款允许自动化）且有分数的路径。默认只计入我们实测通过的路径；勾选 「含未确认的」 后，标称免费但我们尚未跑通的路径也会计入。

## 每日免费 token 走势

首页（「免费时段」下方）按渠道绘制每日估算免费 token 量，从 2026-10-04 到今天。

- **单位。** 每日估算 token 量，单位 M。每条免费线路的量来自其吞吐量档位（taste = 0.3M、daily = 3M、bulk = 30M），除非厂商公布了 TPD/RPD，此时按官方数字折算（1 次请求 = 8k token）并标为实测。没有吞吐量档位的免费线路不计入，其数量显示在图表下方。
- **额度池。** 共享额度的免费线路（渠道 `limit_scope` 或共享免费条件，如 Zen 按 IP、Cloudflare 每天 10k Neurons、ModelScope 每日共享）每天只算一次，取池内达标模型里最大的一份；其余按线路各自计数。
- **智力门槛。** 按 FTI 分段：全部 / 20+ / 25+ / 30+ / 35+ / 50+，默认 30+。只有模型的 FTI（区间模型取中心值）达到门槛的免费线路才计入。
- **渠道组合。** 常用（无需付费、无需大陆实名、form 为 api 或官方 CLI）/ 全部 / + 最低付费（加入需要付费套餐的渠道）。规则含 `no_automation` 的 `own_cli` 渠道只出现在「全部」里。
- **堆叠。** 按渠道堆叠；区间内总量前 6 的渠道各一色，其余合并为灰色「其他 N」。斜线纹为档位估算，实色为官方数字折算。
- **最高免费 FTI。** 红线为所选组合下最高的免费 FTI（与门槛无关、与组合有关）。
- **事件标记。** 自动挑区间内对总量影响最大的 ≤4 个日子，标短标签，如「Zen −3 条线路」或「某模型 +」。
- **右侧统计卡。** 现在 / 30 天最高 / 30 天最低 / 最高免费 FTI。
- **明细。** 可折叠的渠道 × 日期热图；单元格颜色为该渠道当天最强免费模型的 FTI 档。
- **模型数视图。** 单独的切换按钮绘制达到门槛的不同免费模型数（单条阶梯线），从最早数据日期起；统计卡变为 现在 / 历史最多 / 历史最少。
- **页面上没有说明句。** 页面上的每个词都是数据或数据标签；解释写在这里（ADR-016）。

## 厂商

每个模型都在 `data/makers.json` 中指向一个厂商（名称、母公司、国家、官方链接）。同一家公司的不同写法在那里合并（例如 THUDM 归到 Z.ai 名下）。未公开模型归属 "Undisclosed"（未公开）；当社区把某个模型同某厂商联系起来时，该模型会带上 `suspected_maker` 及其来源，在模型页显示为 「可能 X · 未确认」，并在该厂商页单独列为 「可能归属该厂商」列表。它绝不被算作该厂商自己的模型。

## 厂商自报数字与对比表（ADR-023）

厂商会在自己的评测框架里报告自家模型的基准分数，而小模型在编码基准上的分数往往明显高于其总体智能所应得出的水平。把这些原始数字直接套用一个从独立排行榜学来的拟合线，会高估它们。所以出自对比表的厂商分数，会与同一张表里的其他模型对照读取：对每个有已知参考分、且基准分数相差不超过 10 分的对比模型，隐含 FTI 为该模型的参考分加上拟合线斜率乘以分差，越接近的模型权重越大。没有可用对比模型的厂商自报分数，有厂商线的话按厂商线换算，权重最低；当它们是唯一来源时只显示区间，并标为低可信度。

## 隐私与复查

本站不设 cookie，也不记录会话。页面浏览量与点击了哪些外链由 PostHog 统计（欧盟托管、仅存内存、IP 匿名化、尊重 Do Not Track）；页面展示时向自家服务器发一个空请求（用于区分人与爬虫，不携带任何标识符）；并读取标准 web 服务器日志（页面、时间、referrer、user agent）来统计访问量与 AI 爬虫。没有任何东西能跨访问识别你；具体机制见 OBSERVE.md。一条有效免费线路若 7 天未复查，就被标为"待复查"，在重新核查之前不再计入已确认。

## 免费计划（offers）

免费线路指的是某个模型在某渠道上费用为 $0，并带有只为阻止滥用而设的上限。免费计划给你的则是可以在多个模型之间通用的一些东西：额度、每日发放量（Neurons、Freebucks、一份共享调用配额）、学生计划，或随你已在付费的套餐附带的一项权益。计划有自己的独立页面（/offers），绝不与模型一起排名；模型页把它们列在 「也可通过以下计划免费使用」之下。数量保留各厂商自己的单位，从不折算。列表按计划拿到的难易排序（要求最少的在前），其次按补充频率。只列出官方且合规的途径。一个计划 14 天未复查即待复查。

## 额度池型线路（meter: pooled）

当多个模型共享同一个额度池而不是各自拥有独立限额时，该线路为 "pooled"。`meter` 字段标示类型：`per_model` 表示该模型有自己的限流或额度，`pooled` 表示这些模型共用一个共享池（ADR-033）。池型线路总是带 `pool` 对象：`pool.offer` 指向拥有该池的免费计划（其门槛、注册与额度原文都在那里），`pool.cap` 说明池本身的额度（`amount`、`unit`、`per`）——应把它读作整个池的共享上限，而不是单模型限额。线路自身的 `limits_stated` / `limits_observed` 只描述可达性与怪癖，不说明池大小。因此 `per_model` 线路绝不带 `pool`，而缺少 `pool.offer` + `pool.cap` 的 `pooled` 线路无效。

## 社区风评（不进 FTI）

全新或仍匿名的模型在头几天 FTI 为 `—`，但网上已有大量讨论。模型页的「社区风评」区块按 `tools/community/CODEBOOK.md` 的规则把这些讨论编成可计数的格子：大家给它的级别、常被拿来比较的模型及方向、疑似厂商（一律标为传闻）、参数量猜测、擅长与短板、已知问题、作者报出的硬数字、整体好恶与平台构成。每一格都是帖数的计数，区块附几张自渲染引文卡（平台、作者、日期、≤25 词的原样引文、链接；来源若后来消失则保留并标为已删帖）。不加载来自 X、Reddit 或任何平台的第三方嵌入。

区块怎么画：计数画成一排小横条，一条代表一帖，不写成句子里的数字。没话说的格子整格不画——空格子、「其他」这种兜底分类、「未讨论」这种占位话都不留格子；同一个词在「短板」和「已知问题」里都出现时只说一次。任何宽度下每个格子最多两行正文，装不下的收进一个「+N 条」里，疑似厂商与帖内数字也一样收。帖内数字每个词只说一次：当单位或指标只是在重复数值本身（数值「mismatch」配指标「tokenizer match」、数值「6 toy tasks」又带单位「tasks」），重复的词只出一次；发帖者原本的说明仍留在这一行的悬停提示里。引文卡一行最多三张、同一行等高；最后一行不满时那几张自己摊满这一行，旁边不留空位。

它刻意不属于 FTI：这些内容不进分数（页脚写「不计入 FTI」）。独立作者少于 3 位时，区块只写「讨论还太少」。对标估分（用新模型被比较的模型反推出的 FTI）只作为私有回测数据计算，绝不公开、也不上页面。若某帖或引文有错或需要下架，请开 GitHub issue。
