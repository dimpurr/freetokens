# freetokens

Where can you use a capable LLM for free **right now**, through which channel, under which conditions, and **until when**?

freetokens tracks **free lanes**: one model × one channel × one free condition. It focuses on what other lists miss: limited-time free models inside **subscription and agent tools** (OpenCode Zen / Go, Command Code, …) and on routers, **when each offer started and is expected to end**, and limits **we measured ourselves** (for example, how many agents can run in parallel).

**Website:** https://freetokens.fyi (ending-soon countdown, a chart against today, a page for every model and channel).

## How to contribute

Spotted a new free model, an end date, a takedown, or a limit you measured? Two ways:

1. **Open an issue** with the link and what changed. Anyone can do this; we turn it into data.
2. **Open a pull request** that edits the JSON in [`data/`](data/). Every fact needs a source link and a date. Run `python3 build.py --validate` before you submit.

Full guide and rules: **[CONTRIBUTING.md](CONTRIBUTING.md)**.

## How to read this

- **Every fact carries a date and a source.** A row is only as good as its check date; old means stale.
- **Unknown is written as unknown:** `unstated` = the provider says nothing; `not checked` = we haven't looked; `not recorded` = we saw it but didn't keep the detail.
- **Measured limits** are one-off light readings from our own account, with their date. They are not load tests and not guarantees.
- Post times on X are decoded from the post ID (UTC).

## Scope

- **In scope:** models you can call for free (no per-token charge) through a public channel, including those that need an account or a paid plan in which the model costs zero credits.
- **Out of scope (for now):** subscription prices and quotas in general (see [tokenplans.dev](https://tokenplans.dev)); permanent free API tiers in general (see [freellm.net](https://freellm.net)); institutional or private gateways.
- Nothing here is a load test. Please don't stress-test shared free tiers.
