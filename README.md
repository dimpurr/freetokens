# freetokens

Where can you use a capable LLM for free **right now**, through which channel, under which conditions, and **until when**?

A hand-curated demo (v0). It tracks **free lanes**: one model × one channel × one free condition. The focus is on what existing lists miss: limited-time free models inside **subscription and agent tools** (OpenCode Zen / Go, Command Code, …) and router listings, together with **when each offer started and is expected to end**.

**Visual version:** https://freetokens.fyi has the ending-soon countdown, a lane chart against today's date, and filterable tables. The same page is generated as `index.html` in this repo.

## How to read this

- **Every fact carries a date and a source.** A row is only as good as its `Checked` date. If that date is old, treat the row as stale.
- **Unknown is written as unknown**, never left blank: `unstated` means the provider says nothing; `not checked` means we haven't looked; `not recorded` means we saw it but didn't keep the detail.
- **Observed limits** are one-off light readings from our own account, with their date. They are not load tests and not guarantees.
- Post times on X are decoded from the post ID (UTC).

- **Checked by:** **agent run**: A real coding-agent task completed and independently verified · **API call**: A successful direct API request · **catalogue**: Read the provider's model list, no successful call · **listing only**: Read the model's web page, no call
- **Channel type:** **agent tool**: A coding-agent product or its gateway (OpenCode Zen / Go, Command Code, …) · **router**: A multi-provider API router (OpenRouter, …) · **first-party**: The model maker's own API or app

## Scope and method

- **In scope:** models you can call for free (no per-token charge) through a public channel, including those that need an account or a paid plan in which the model costs zero credits.
- **Out of scope (for now):** subscription prices and quotas in general (see [tokenplans.dev](https://tokenplans.dev)); permanent free API tiers in general (see [freellm.net](https://freellm.net)); institutional or private gateways.
- Nothing here is a load test. Free shared tiers are not to be stress-tested.

## Editing

All data lives in `data/` (`lanes.json`, `events.json`, `models.json`). Field rules and legend vocabularies live in `schema/schema.json`. After editing, run:

```sh
python3 build.py          # validate, then regenerate the tables above and index.html
python3 build.py --check  # validate and confirm the generated files are current
```

Everything between `BEGIN` / `END` markers is generated. Edit the prose outside them by hand.
