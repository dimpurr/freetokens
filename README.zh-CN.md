# freetokens

哪里能**此刻**免费用到一个够强的 LLM，经由哪个渠道、满足哪个条件，并且**能用到哪一天**？

freetokens 追踪的是**免费线路**：一个模型 × 一个渠道 × 一个免费条件。它关注别的清单漏掉的东西：**订阅与 agent 工具**（OpenCode Zen / Go、Command Code，……）以及路由器内部的限时免费模型、**每个免费计划何时开始、预计何时结束**，还有**我们实测**的限制（例如能同时跑多少个 agent）。

**网站：** https://freetokens.fyi（即将到期倒计时、对照今天的图表、每个模型和每个渠道各有一个页面）。

## 如何贡献

发现了新的免费模型、一个结束日期、一次下架，或你自己测出的限制？两种方式：

1. **开一个 issue**，附上链接和变了什么。任何人都能这样做；我们把它整理成数据。
2. **开一个 pull request**，修改 [`data/`](data/) 里的 JSON。每条事实都需要来源链接和一个日期。提交之前运行 `python3 build.py --validate`。

完整指引与规则：**[CONTRIBUTING.md](CONTRIBUTING.md)**。
